# UnitTests

An interactive graphics-test application with selectable tests for shaders, vertex and index buffers, uniform buffers, and textures. These tests run through the GraphicsFramework application and rendering systems.

This is an optional CMake sample target and links against the `GraphicsFramework` library. See the [repository README](../../README.md) for Visual Studio solution generation and build instructions. Enable sample targets with `-DGF_BUILD_SAMPLES=ON` when configuring CMake.
