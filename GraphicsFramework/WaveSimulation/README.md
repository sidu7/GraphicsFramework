# WaveSimulation

A GraphicsFramework sample application demonstrating wave simulation using a height field. The simulation and rendering shaders are maintained in `src` and `res`.

This application is an optional CMake sample target and links against the `GraphicsFramework` library. See the [repository README](../../README.md) for Visual Studio solution generation and build instructions. Enable sample targets with `-DGF_BUILD_SAMPLES=ON` when configuring CMake.
