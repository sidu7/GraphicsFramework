# VulkanTest

A standalone SDL2 and Vulkan sample that demonstrates Vulkan instance/device setup, swap-chain creation, and rendering. It uses Vulkan directly rather than the `GraphicsFramework` renderer interface.

This legacy sample is not currently included as a CMake target. Its source and shader files remain in this directory. See the [repository README](../../README.md) for the supported CMake targets and Visual Studio configurations.
