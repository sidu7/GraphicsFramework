## 5. Phase 0.5 — Framework prerequisites

Both Track A and Track B need these two fixes. They are small, surgical, and independently verifiable against the reference samples.

### P0.5-01 — Enable `extendedDynamicState` on the Vulkan device

**Why:** `DeviceVK::Draw` calls `vkCmdSetCullMode`, `vkCmdSetFrontFace`, `vkCmdSetPrimitiveTopology` and `vkCmdSetDepthTestEnable`, and `ShaderVK` declares all four as dynamic states. Those commands are only legal when `VkPhysicalDeviceVulkan13Features::extendedDynamicState` is enabled. The device is created with `pEnabledFeatures = nullptr` and no `pNext` chain, so the feature is off. Today this "works" only because desktop drivers are lenient; with validation on it is an error, and depth testing is unreliable.

**Files:** `GraphicsFramework/GraphicsFramework/Source/RHI/Vulkan/Internal/HelperVK.cpp`

**Edit 1** — find:

```cpp
				VkDeviceCreateInfo DeviceInfo = { VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO };
```

Insert immediately **before** it:

```cpp
				// The RHI toggles cull mode, front face, topology and depth-test enable
				// through dynamic state commands, so the extended dynamic state feature
				// (core in Vulkan 1.3) has to be enabled on the logical device.
				VkPhysicalDeviceVulkan13Features Vulkan13Features = { VK_STRUCTURE_TYPE_PHYSICAL_DEVICE_VULKAN_1_3_FEATURES };
				Vulkan13Features.extendedDynamicState = VK_TRUE;

				VkPhysicalDeviceFeatures2 PhysicalFeatures2 = { VK_STRUCTURE_TYPE_PHYSICAL_DEVICE_FEATURES_2 };
				PhysicalFeatures2.pNext = &Vulkan13Features;
				vkGetPhysicalDeviceFeatures2(VkRenderer->PhysicalDevice, &PhysicalFeatures2);
				if (Vulkan13Features.extendedDynamicState != VK_TRUE)
				{
					std::cout << "Vulkan device does not support extendedDynamicState; the RHI requires Vulkan 1.3." << std::endl;
				}
```

**Edit 2** — find:

```cpp
				DeviceInfo.pEnabledFeatures = nullptr;
```

Replace with:

```cpp
				DeviceInfo.pNext = &Vulkan13Features;
				DeviceInfo.pEnabledFeatures = nullptr;
```

(Leave `pEnabledFeatures` as `nullptr`; the feature chain goes through `pNext`.)

**Verify:**

```powershell
cmake --build --preset Vulkan-Debug --target UnitTests --parallel
powershell -ExecutionPolicy Bypass -File scripts\verify-scene.ps1 -Preset Vulkan-Debug -Scene 0
powershell -ExecutionPolicy Bypass -File scripts\verify-scene.ps1 -Preset Vulkan-Debug -Scene 4
```

Expected: both scenes `RESULT : PASS`; the stdout/stderr files contain **no** `VUID-` line mentioning `VUID-vkCmdSetDepthTestEnable` or `VUID-vkCmdSetCullMode`.

**Stop if:** the device reports `extendedDynamicState` unsupported (the message added above). That machine cannot run the Vulkan backend at all; report it.

**Commit:** `fix(vulkan): enable extendedDynamicState on the logical device`

### P0.5-02 — Rewrite `VertexBufferVK` as a host-visible buffer

**Why:** three defects make every dynamic vertex buffer unusable on Vulkan:

1. `AddSubData` copies through `StagingBufferInfo` and then **destroys** it (`OnCopyFinish`), so the second call maps a null allocation.
2. `QueueCopyCommands` copies the whole buffer from offset 0 and ignores the requested offset.
3. `AddDynamicData(nullptr, size)` memcpy's from `nullptr` and crashes.

`WaveSimulation` uploads 4096 vertices every frame; `AnimationTechniques` rebuilds its curve buffer. Both need a working dynamic buffer. The simplest correct implementation is a host-visible buffer that is written directly, with no staging at all. These meshes are small (a few hundred KB), so the bandwidth cost is irrelevant.

**Files:** `GraphicsFramework/GraphicsFramework/Source/RHI/Vulkan/VertexBufferVK.h`, `GraphicsFramework/GraphicsFramework/Source/RHI/Vulkan/VertexBufferVK.cpp`

**Edit 1 — `VertexBufferVK.h`**: replace the whole class body between `protected:` and the closing brace.

Find:

```cpp
	BufferInfo StagingBufferInfo;
	BufferInfo MainBufferInfo;
protected:
	void CreateBufferInfo(uint32_t vertexDataSize);
```

Replace with:

```cpp
	BufferInfo StagingBufferInfo;   // unused, kept for ABI/source compatibility
	BufferInfo MainBufferInfo;
protected:
	void EnsureCapacity(uint32_t requiredSize);
	void WriteAt(const void* data, unsigned int size, unsigned int offset);
```

**Edit 2 — `VertexBufferVK.cpp`**: replace everything from `void VertexBufferVK::AddData` to the end of `Delete()` with:

```cpp
void VertexBufferVK::AddData(const void* data, unsigned int size)
{
	EnsureCapacity(size);
	if (data && size > 0)
	{
		WriteAt(data, size, 0);
	}
}

void VertexBufferVK::AddSubData(const void* data, unsigned int size, unsigned offset)
{
	// A null pointer means "allocate/reserve only" (that is how AddDynamicData is used).
	if (data == nullptr || size == 0)
	{
		EnsureCapacity(offset + size);
		return;
	}

	EnsureCapacity(offset + size);
	WriteAt(data, size, offset);
}

void VertexBufferVK::AddDynamicData(const void* data, unsigned int size)
{
	EnsureCapacity(size);
	if (data && size > 0)
	{
		WriteAt(data, size, 0);
	}
}

VkFormat VertexBufferVK::GetVertexFormat(VertexFormat format)
{
	switch (format)
	{
		case VertexFormat::Bool:   return VK_FORMAT_R8_UNORM;
		case VertexFormat::UInt:   return VK_FORMAT_R32_UINT;
		case VertexFormat::Int:    return VK_FORMAT_R32_SINT;
		case VertexFormat::iVec2:  return VK_FORMAT_R32G32_SINT;
		case VertexFormat::iVec3:  return VK_FORMAT_R32G32B32_SINT;
		case VertexFormat::iVec4:  return VK_FORMAT_R32G32B32A32_SINT;
		case VertexFormat::Float:  return VK_FORMAT_R32_SFLOAT;
		case VertexFormat::Vec2:   return VK_FORMAT_R32G32_SFLOAT;
		case VertexFormat::Vec3:   return VK_FORMAT_R32G32B32_SFLOAT;
		case VertexFormat::Vec4:   return VK_FORMAT_R32G32B32A32_SFLOAT;
		case VertexFormat::Mat2:
		case VertexFormat::Mat3:
		case VertexFormat::Mat4:
		default:                   return VK_FORMAT_UNDEFINED;
	}
}

void VertexBufferVK::EnsureCapacity(uint32_t requiredSize)
{
	if (requiredSize == 0)
	{
		return;
	}

	if (MainBufferInfo.Buffer != VK_NULL_HANDLE && MainBufferInfo.Size >= requiredSize)
	{
		return;
	}

	Device* VkDev = Device::Get();
	if (MainBufferInfo.Buffer != VK_NULL_HANDLE)
	{
		VkDev->DestroyBuffer(MainBufferInfo);
	}

	// Grow in powers of two so a per-frame upload pattern does not reallocate.
	uint32_t Capacity = MainBufferInfo.Size > 0 ? MainBufferInfo.Size : 256;
	while (Capacity < requiredSize)
	{
		Capacity *= 2;
	}

	MainBufferInfo = VkDev->CreateBuffer(Capacity,
		VK_BUFFER_USAGE_VERTEX_BUFFER_BIT | VK_BUFFER_USAGE_TRANSFER_DST_BIT,
		true /*bHostVisible*/);
}

void VertexBufferVK::WriteAt(const void* data, unsigned int size, unsigned int offset)
{
	Device* VkDev = Device::Get();

	uint8_t* Destination = static_cast<uint8_t*>(VkDev->MapBuffer(MainBufferInfo, offset));
	memcpy(Destination, data, size);
	VkDev->UnmapBuffer(MainBufferInfo);

	// vmaFlushAllocation is valid on host-visible memory whether or not it is coherent.
	VkDev->FlushBuffer(MainBufferInfo, offset, size);
}

void VertexBufferVK::SetDataLayout(const std::vector<VertexFormat>& vertexFormats)
{
	uint16_t Offset = 0;

	mVertexLayouts.clear();
	mVertexLayouts.resize(vertexFormats.size());
	for (uint16_t i = 0; i < vertexFormats.size(); ++i)
	{
		mVertexLayouts[i].mOffset = Offset;
		mVertexLayouts[i].mFormat = vertexFormats[i];
		Offset += GetFormatSize(vertexFormats[i]);
	}

	mStride = Offset;
}

void VertexBufferVK::Delete()
{
	Device* VkDev = Device::Get();

	VkDev->DestroyBuffer(StagingBufferInfo);
	VkDev->DestroyBuffer(MainBufferInfo);
}
```

**Notes:**

- `Device::MapBuffer(buffer, offset)` returns `allocationPointer + offset`, so `WriteAt` passes the buffer offset through and memcpy's at the right place.
- `Device::FlushBuffer` calls `vmaFlushAllocation`; on coherent memory it is a no-op that returns `VK_SUCCESS`.
- Do **not** keep the old `CreateBufferInfo`; it is replaced by `EnsureCapacity` and the header no longer declares it.
